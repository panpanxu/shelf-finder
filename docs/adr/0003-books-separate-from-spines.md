# 「书」从「书脊」里拆出来：书脊属于照片，书独立存在并被书脊认领

第一版里只有书脊，它是照片的一部分：照片删了或重新识别，书脊就没了，标签、豆瓣链接这类补充信息没有地方挂，书搬了架子也只能整张重拍。现在书是独立对象，书名、标签、豆瓣条目链接、改编作品都挂在书上；书脊仍属于照片，但指向一本书。

新书脊入库时按文字认领已有的书：书名去空白转简体后全文比对，每十个字允许一处编辑，短书名必须完全一致；同一张照片上已经有书脊指向的书不能再被认领，那是另一册。认领不上的新建一本书并自动贴标签。重新识别只换书脊，书留着让新书脊认领回来，所以补充信息不丢。改书脊文字等于改正书名，书名跟着变。

书的位置是推导出来的：指向它的书脊里照片最新的那条。使用者明确删掉书脊或照片时，没有书脊指向的书一起删掉；重新识别没读出来的书不删，搜索结果里归到「不在任何照片上」一组，等下次识别再认领。所以书搬家要先拍新架子再删旧照片，顺序反了补充信息会随旧照片一起删掉。

## Considered Options

- 继续把信息挂在书脊上：重新识别就丢，书搬家就断。
- 没有书脊的书一律保留：删照片、删误识的行之后留下一堆「不在任何照片上」的书，搜索结果里全是垃圾。
- 跨照片也把同名书当两本：无法区分「搬走了」和「第二册」，而搬家是常态，所以跨照片认领，同照片才算另一册。
