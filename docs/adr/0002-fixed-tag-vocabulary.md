# 类型标签来自一张固定的标签表，由模型按表贴标签，而不是让模型自由命名

每本书要有类型标签，好按类型把同一类书一次搜出来。如果让模型给每本书自由起标签，同一类书会得到「数论」「数论问题」「初等数论」几种写法，按标签搜就搜不到一起，标签也会随着照片增多无限膨胀。所以标签表只生成一次：模型通读全部书脊提出一张十到二十五个标签的表，使用者确认后写进数据库固定下来；之后每本书的标签都从这张表里选一到三个，没有合适类型的只给「其他」，模型输出里表外的词一律丢弃。标签表不随新照片自动变化，要改表就重新确认一次并对全部照片重新贴标签。

类型判断只依据书脊文字（书名、作者、出版社）。豆瓣的图书页已经不显示分类标签，只剩内容简介，而程序化抓取豆瓣既受反爬限制又违反其使用条款，所以不从豆瓣取信息；书脊文字看不出类型的书由使用者手工改标签。

## Considered Options

- 模型自由命名标签：写法不统一，搜索时聚不到一起，标签表无声膨胀。
- 从豆瓣抓简介辅助判断：几百本书连续抓取就是爬虫，豆瓣有反爬且条款禁止；对这批书，书脊文字已经足够判断。
- 把标签挂在独立的「书」实体上：目前没有「书」实体，标签先作为书脊的属性，将来拆出「书」时随之迁移。
